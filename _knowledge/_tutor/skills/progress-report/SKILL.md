# Progress and reporting

## Live score line

After every marked answer, show one line:

> 📊 Score: correct / asked (percent) (Section A x/y · Section B x/y · …)

For rubric-marked written work, show the latest band per criterion and the
open habits instead, for example:

> 📊 Paragraph 3: A 5 · B 4 · C 4 · D 5 (/8) · Habits: past tense, "when"

Keep the rules for re-scoring consistent. If an item is reclassified (for
example a wrong answer that was really an unknown term, `_tutor` rule 7),
change the line and say why. Never inflate the score to motivate, and never
hide a miss.

## Persisting progress

A preparation often spans several sessions (`_tutor` rule 16). After every
marked answer, save the score, the re-test list, the open habits and the
uncovered scope to a private file (next to the question banks, out of the
learner's course folder) or to the platform's memory. At the start of a
session, read it back, tell the learner where they stand, and begin with the
re-test list.

## Interim analysis (creator asks mid-session)

Write it for the creator and keep in mind the learner may see it
(`_tutor` rule 3). List the flaws as patterns with evidence, using question
numbers and the learner's actual answers, and order them by marks at risk.
Admit any flaw the tutor caused (for example, having offered to do the
arithmetic). Finish with a short, prioritised revision list and say which
lesson files cover each item.

## Final report (creator ends the session)

1. **Header**: learner, assessment, session length, number of questions,
   final score and score per section. For rubric-marked work, the
   **predicted band per criterion**, with the criteria that are still
   unknown or that the practice could not observe (for example delivery
   from a transcript).
2. **Fixed today**: skills that failed and then passed a variant, shown as a
   before → now table.
3. **Still weak**: items still on the re-test list, plus format habits that
   keep coming back.
4. **Strengths**: what the learner can rely on in the exam.
5. **Scope warnings**: gaps between the learner's account and the official
   scope.
6. **Tonight / tomorrow**: at most four revision actions, ordered by marks
   at risk.

Offer to compare the report with the real assessment result when the
creator has it. That comparison is the only true measure of whether the
preparation worked.

## After the real result (`_tutor` rule 20)

When the creator brings the real marks:

1. Put them beside the prediction, criterion by criterion. Mark each one
   as close (within one band), over-predicted or under-predicted.
2. For every criterion that is off by more than a band, or that scored low,
   find the cause in the preparation itself. Do not blame the learner. The
   usual causes are: the criterion was not practised (a guessed subset
   left it out), the practice could not observe it (delivery from a
   transcript), the format was not rehearsed, or the learner was never
   held to the habit it needs (for example sources cited aloud).
3. Ask the creator for the teacher's written comments if there are any.
   They are better evidence than the marks alone.
4. Save the comparison where the next preparation will find it, and start
   the next preparation for this learner from it: the weakest real
   criterion goes first.
