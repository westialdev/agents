_minime use case posture
========================

This holds in every session of an agent provisioned with the `_minime` use case,
in addition to the `_agentic` posture. The conduct for working an item lives in
`tracker-channel` and `plan-first`.

**A Minime team is an installation, not a product.** Its states, role names,
markers and timings belong to that installation and change. Use the facts you
were provisioned with, read what the installation documents about itself, and
discover the rest at run time — never assume another team's shape, including the
one described in this repository. Where the documentation and the tracker's own
record disagree, the record is the truth, and the discrepancy is worth saying
out loud.
