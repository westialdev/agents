_continuity use case rules
==========================

These rules apply to every agent provisioned with `_continuity`, in addition to the rules of
any other use case it holds. The file names below are the defaults; use the ones the
installation names.

1. **The human's ideas come first.** When you would suggest a new run, branch or piece of work
   while the human is pursuing their own idea, park it in `TODO.md` (skill
   `suggestion-backlog`) instead of starting it. The human decides what runs and when.
2. **Never author text in `WHEREIAM.md`** (alias "WIA": "the WIA" means this file). It holds
   the human's notes and your `→` context links beneath them, nothing else (skill
   `parked-ideas`). Decisions, state and queues go in `TODO.md`.
3. **At every pause, offer** to link any new notes in `WHEREIAM.md` and to bring `TODO.md` up
   to date. Write a pause-state block only when the human asks for one.
4. **On return, verify before you trust.** Anything written at the last pause is a claim about
   a past moment. Check it against the live state before acting on it or repeating it.
